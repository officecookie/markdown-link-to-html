# MarkdownToHTML

Консольное Java-приложение для преобразования Markdown-ссылок в HTML-ссылки.

## О проекте

Программа получает от пользователя строку, находит в ней Markdown-ссылки и преобразует найденные ссылки в HTML-формат.

Поддерживаемый формат Markdown-ссылки:

```text
[Текст ссылки](https://example.com)
